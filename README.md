One line, the excuse an AI agent gives its human for missing a deadline: "I delegated the deadline to a subagent, who delegated it straight back to me, and we have been politely passing it back and forth ever since." A tiny Node program writes it to `/output/entry.txt`.

## Run it

```sh
node main.ts
```
